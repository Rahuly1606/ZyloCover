# ========================================
# 5. HOW THE INTEGRATION WORKS
# ========================================

"""
Request Flow:

User POST /pricing/calculate
    ↓
Backend gets user zone (e.g., zone_d_residential)
    ↓
Calls: env_service.get_snapshot(zone="zone_d_residential")
    ↓
Environmental Service tries:
   1. OpenWeatherMap API → Get temperature, wind, rainfall
   2. WAQI API → Get Air Quality Index
   3. Parallel requests (async/await) - takes ~1-2 seconds
    ↓
SUCCESS? Return real data + source="openweathermap+waqi"
FAIL? Return mock data + source="mock"
    ↓
Pricing Engine uses this data:
   - rainfall_mm affects frequency loading
   - temp_c affects severity
   - aqi affects frequency loading
   - wind_kmph affects loadings
    ↓
Premium calculated with REAL environmental factors
    ↓
Return to user with breakdown
"""

"""
❌ API Keys not working?
   → Verify in .env: OPENWEATHER_API_KEY=xxx (no typos)
   → Check API key is from correct service (not reversed)
   → Test API manually: python -c "import httpx; print(httpx.get('...'))"

❌ Still getting mock data?
   → Check .env: USE_MOCK_ENV_DATA=False (must be False)
   → Check logs: grep "Real API fetch failed" logs.txt
   → Restart backend: Ctrl+C then python app/main.py

❌ Slow responses?
   → API calls might be timing out (default 5s)
   → Try: curl -v http://localhost:8000/pricing/calculate (watch timing)
   → Increase WEATHER_API_TIMEOUT=10 if needed

❌ None of the above?
   → Check internet connection
   → Check firewall not blocking API calls
   → Fall back to mock data (set USE_MOCK_ENV_DATA=True)
"""
