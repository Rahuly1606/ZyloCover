HOW IT WORKS END-TO-END
========================

1. User opens Dashboard
   ↓
2. Frontend calls pricingService.calculatePricing()
   ↓
3. Backend endpoint /pricing/calculate activated
   ↓
4. Backend fetches REAL environmental data:
   - Calls OpenWeatherMap API
   - Calls WAQI API (in parallel)
   - Gets temperature, rainfall, AQI, wind
   - Checks against thresholds
   ↓
5. Backend returns pricing response WITH environmental data:
   {
     "weekly_premium": 185.42,
     "data_source": "openweathermap+waqi",
     "environmental_snapshot": {
       "temp_c": 36.2,
       "rainfall_mm": 12.5,
       "aqi": 142,
       "wind_kmph": 18.2,
       "active_triggers": []
     }
   }
   ↓
6. Frontend receives response
   ↓
7. EnvironmentalSnapshot component displays:
   - 📍 Zone: zone_d_residential
   - 🌡️ Temperature: 36.2°C (Status: ✅ Normal)
   - 💧 Rainfall: 12.5mm (Status: ✅ Light/None)
   - 🏭 AQI: 142 (Status: 😷 Moderate)
   - 💨 Wind: 18.2 km/h (Status: ✅ Light)
   - 📊 Data Source: Real API ✅
   ↓
8. If triggers active:
   - WeatherAlert component displays
   - Shows which events triggered
   - Shows severity percentage
   - Shows payout multiplier
   - Informs user about auto-processing

TROUBLESHOOTING
===============

Problem: Environmental data not showing
Solution:
1. Check Backend logs for "✅ OpenWeatherMap API"
2. Verify API keys in .env
3. Check .env has USE_MOCK_ENV_DATA=False
4. Restart backend: Ctrl+C then python app/main.py

Problem: Shows "mock" data instead of real API
Solution:
1. Verify API keys are correct
2. Check internet connection
3. Make sure OpenWeatherMap/WAQI APIs are responding
4. Increase WEATHER_API_TIMEOUT if network slow

Problem: No active triggers showing
Solution:
1. Check current weather conditions
   - Temperature < 42°C
   - Rainfall < 50mm
   - AQI < 300
   - Wind < 60 km/h
2. If all below thresholds, no triggers (correct behavior)
3. Simulate trigger to test: POST /trigger/simulate?zone=zone_d_residential

Problem: Frontend components not importing
Solution:
1. Verify file paths match exactly
2. Check imports in Dashboard.tsx:
   import { EnvironmentalSnapshot } from '@/components/EnvironmentalSnapshot'
   import { WeatherAlert } from '@/components/WeatherAlert'
3. Run: npm run build (check for errors)
